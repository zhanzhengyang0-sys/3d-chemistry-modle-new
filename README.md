# 六元环的高中化学 · 3D 结构模型库

一个**纯静态、零依赖、可离线**的高中化学 3D 结构模型库，共 **97 个交互式模型**，打开网页即可用鼠标旋转、滚轮缩放，适合课堂投屏与课后自学。

> 在线访问：<https://zhanzhengyang0-sys.github.io/3d-chemistry-modle/>

---

## ✨ 功能特点

| 分类 | 数量 | 内容示例 |
| --- | --- | --- |
| 🔮 晶体结构 & 堆积方式 | 33 | C60 晶胞、金刚石、NaCl、CaF₂、CsCl、ZnS、尖晶石、钙钛矿、均摊规律、四种堆积方式 |
| ⚛️ 电子云模型 & 原子轨道 | 15 | 1s–3d 各轨道电子云、sp³ 杂化轨道 |
| 🧬 有机物结构 & 共线共面 | 21 | 甲烷、乙烯、乙炔、苯、苯酚、联苯、环己烷、1,3-丁二烯 |
| 🔷 其他物质的结构 | 27 | 碳纳米管、白磷、黑磷、S₈、SF₆、冠醚、DNA、MOF、配离子 |
| 📈 数据与曲线 | 1 | 溶液离子平衡曲线 |

- **完全离线**：three.js 运行库、样式、图片全部内置，断网可用，不请求任何 CDN。
- **零安装**：无需 Node、无需构建，双击 `index.html` 就能运行。
- **双主题**：右上角可切换「☀ 纯白模式 / 🌙 星空模式」，选择会被记住，投屏时用纯白模式最稳。
- **即时搜索**：首页搜索框按名称过滤并定位到对应分类。

## 🚀 本地使用

1. 下载或克隆本仓库；
2. 用 Chrome / Edge 打开根目录的 `index.html`；
3. 点击卡片进入模型，右上角「← 返回目录」，`F11` 全屏。

> ⚠️ 整个目录必须一起拷贝。单独拷一个 `.html` 文件会白屏，因为它依赖同级 `libs/` 目录。

## 📁 目录结构

```
.
├── index.html               # 目录页（入口）
├── 001_*.html … 097_*.html   # 97 个模型页，编号沿用原站分类顺序
├── libs/                    # three.js 运行库（three.min.js / OrbitControls / CSS2DRenderer）
├── theme/                   # 首页皮肤：cosmos.css / cosmos.js
├── assets/                  # 二维码等图片资源
├── 使用说明.txt              # 30 秒上手说明
└── .nojekyll                # 关闭 Jekyll 处理，保证静态文件原样发布
```

## 🌐 部署说明

本站通过 **GitHub Pages** 发布，源为 `main` 分支根目录：

- 访问地址：`https://<用户名>.github.io/<仓库名>/`
- 所有页面内部链接均为**相对路径**，因此放在仓库子路径下也能正常工作；
- `.nojekyll` 用于跳过 Jekyll 构建，避免静态资源被额外处理。

如需更新：直接替换或新增 HTML 文件，并在 `index.html` 的 `modelData` 中登记条目即可，推送后约 1 分钟自动生效。
